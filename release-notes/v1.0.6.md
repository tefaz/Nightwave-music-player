This release makes library browsing, playback, metadata editing, and phone syncing more reliable.

### What's improved

- Edit an MP3 song's title, artist, or album directly in its row with a slow double-click. A fast double-click still starts playback.
- Playback keeps the queue you started while you browse or filter other playlists. Shuffle avoids immediate repeats, and Previous retraces your listening order.
- Folder scans show progress, reuse metadata for unchanged files, and retain readable songs when another file or folder cannot be read.
- Phone syncing checks existing copies before skipping them, repairs incomplete copies, and distinguishes different songs with the same filename.
- Local library writes and playback cleanup handle failures more reliably.

### Downloads

- **AppImage:** download it, make it executable, and open it.
- **Debian/Ubuntu:** install the `.deb` package.
